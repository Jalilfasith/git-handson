# DevOps Git Training

Private repository for Git and GitHub training.

## Branch Strategy
- main: Stable release branch
- dev: Integration branch
- feature/*: Individual changes

## Training Topics
- Git commits and branches
- Pull requests and reviews
- Merge conflict resolution
- Release tagging
- Secure repository management

## Security
Do not commit credentials, API keys or private keys.
Review all staged changes before committing.
Run secret scanning before publishing changes.
